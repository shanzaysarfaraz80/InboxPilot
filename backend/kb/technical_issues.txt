TECHNICAL ISSUES - KNOWLEDGE BASE
===================================

GENERAL RULE FOR ALL TECHNICAL ISSUES:
Always include this exact phrasing somewhere in your reply: "We have received your query and have submitted it to the technical department for review."


Q: The app is not loading / showing a blank screen.
A: Try the following steps: (1) Hard refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac), (2) Clear browser cache and cookies, (3) Try a different browser (Chrome, Firefox, Edge), (4) Disable browser extensions, (5) Check our status page at status.support.com for any ongoing incidents.

Q: I am getting an error 500 / server error.
A: This indicates a server-side issue. Please check status.support.com for ongoing incidents. If the status page shows no issues, please report the error with: the URL you were on, the time it occurred, and any error message shown. Email tech@support.com with these details.

Q: The app is running very slowly.
A: Possible causes: (1) Slow internet connection — test your speed at fast.com, (2) Too many browser tabs open, (3) Browser cache is full — clear it, (4) Our servers may be experiencing high load — check status.support.com, (5) Try using the desktop app instead of the browser version.

Q: I cannot upload files / images.
A: Ensure: (1) File size is under 25 MB, (2) File format is supported (JPG, PNG, GIF, PDF, DOCX, XLSX, ZIP), (3) You have a stable internet connection, (4) Browser permissions for file access are enabled. If the issue persists, try a different browser.

Q: Notifications are not working.
A: Check: (1) Notification settings within the app (Settings → Notifications), (2) Browser notification permissions (click the lock icon in the address bar), (3) OS-level notification settings, (4) Ensure you haven't enabled "Do Not Disturb" mode.

Q: The mobile app keeps crashing.
A: (1) Update to the latest app version from App Store / Google Play, (2) Restart your device, (3) Clear the app cache (Settings → App → Clear Cache on Android), (4) Uninstall and reinstall the app. If crashes persist, report the issue with your device model and OS version to tech@support.com.

Q: Data is not syncing between devices.
A: (1) Ensure you are logged into the same account on both devices, (2) Check your internet connection on both devices, (3) Force a manual sync in Settings → Sync Now, (4) Log out and back in on the affected device.

Q: I forgot my API key. How do I get a new one?
A: Go to Developer Settings → API Keys → Regenerate Key. Note: regenerating invalidates the old key immediately, so update it in your integrations.

Q: The integration with [third-party service] is not working.
A: (1) Re-authenticate the integration: Settings → Integrations → disconnect then reconnect, (2) Check that the third-party service is operational, (3) Ensure required permissions were granted during setup, (4) Check our integrations documentation at docs.support.com/integrations.

Q: I am seeing incorrect data / missing records.
A: (1) Refresh the page, (2) Check if filters are applied that might be hiding records, (3) Verify your data wasn't deleted in the Trash / Archive section, (4) If data is truly missing, contact tech@support.com with the specific record IDs and when the data was last visible.
